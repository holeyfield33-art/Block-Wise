    When do I make a new function?
        
    • You copy-pasted the same blocks twice: make one function and call it.
      • 
        
    • A block group has its own clear job ("check the input", "add up the cart").
      • 
        
    • Nesting goes deeper than 3 levels, or a function has more than about 10 blocks.
    
      
    When do I make a new file?
        
    • One file per topic: checks.py, cart.py, users.py.
      • 
        
    • A file has more than 5 functions, or mixes unrelated jobs.
      • 
        
    • Files talk to each other with imports: from checks import require_positive.
    
      
    When do I make a folder?
        
    • One folder per feature once you have 3 or more related files: auth/users.py, auth/login.py.
      • 
        
    • In Python a folder of modules is a package; add an empty __init__.py when you set it up on disk.
      • 
        
    • Name files and folders after what they do, in lowercase with underscores.
